Vue 3 基础

Vue 3 带来了 Composition API、更快的虚拟 DOM 和更好的 TypeScript 支持——掌握响应式原理、模板语法和组件基础，是 Vue 开发的第一步。

1. 核心概念与定义

Vue是一个渐进式 JavaScript 框架，核心特性是响应式数据绑定和组件化。Vue 3 相比 Vue 2 的主要变化：Composition API、Proxy 响应式、Fragment（多根节点）、Teleport、Suspense、更小的包体积。

响应式系统是 Vue 的核心。当数据变化时，视图自动更新。Vue 3 使用 Proxy 重写了响应式系统，解决了 Vue 2 中 Object.defineProperty 无法检测属性添加/删除、数组索引修改等局限。

组件是 Vue 应用的基本单元。每个组件封装了自己的模板、逻辑和样式，通过 props 向下传递数据，通过 emit 向上发送事件。

2.2 响应式原理

JavaScript// Vue 3 响应式核心（简化版）
function reactive(target) {
  return new Proxy(target, {
    get(obj, key, receiver) {
      track(obj, key); // 依赖收集：记录"谁在读这个属性"
      return Reflect.get(obj, key, receiver);
    },
    set(obj, key, value, receiver) {
      const result = Reflect.set(obj, key, value, receiver);
      trigger(obj, key); // 触发更新：通知"这个属性变了"
      return result;
    }
  });
}

// ref 的本质：用对象包装原始值
function ref(value) {
  return reactive({ __v_isRef: true, value });
}

示例一：组件基础

Vue<!-- UserCard.vue -->
<template>
  <div class="user-card" :class="{ 'is-active': isActive }">
    <img :src="user.avatar" :alt="user.name" />
    <h3>{{ user.name }}</h3>
    <p>{{ user.email }}</p>
    <button @click="toggleActive">
      {{ isActive ? '停用' : '激活' }}
    </button>
  </div>

<script setup>
// 编译时宏，无需 import
defineProps({
  user: {
    type: Object,
    required: true,
  },
});

const emit = defineEmits(['update']);

const isActive = ref(false);

function toggleActive() {
  isActive.value = !isActive.value;
  emit('update', { active: isActive.value });
}
</script>

<style scoped>

示例二：v-model 自定义组件

Vue<!-- CustomInput.vue -->
<script setup>
// v-model 默认绑定 modelValue + update:modelValue
const props = defineProps({ modelValue: String });
const emit = defineEmits(['update:modelValue']);

function onInput(e) {
  emit('update:modelValue', e.target.value);
}
</script>

<template>
  <input :value="modelValue" @input="onInput" />
</template>

<!-- 使用：支持多个 v-model -->
<!-- UserForm.vue -->
<CustomInput v-model="name" />

4. 常见问题与坑点

v-if 和 v-show 怎么选？ +

v-if：条件为 false 时不渲染 DOM，切换时有挂载/卸毁开销。适合条件很少变化的场景。v-show：始终渲染 DOM，用 CSS display 控制显隐，切换开销小。适合频繁切换的场景（如 Tab、弹窗）。

Vue 3 为什么用 Proxy 替代 defineProperty？ +

Proxy 可以拦截：① 属性添加（Vue 2 需 Vue.set）；② 属性删除（Vue 2 需 Vue.delete）；③ 数组索引和长度修改；④ for...in / delete 等操作。Proxy 代理整个对象，无需逐个属性劫持，性能更好。

为什么 v-for 必须加 key？ +

key 是虚拟 DOM diff 算法的节点标识。没有 key 时，Vue 采用"就地复用"策略，可能错误复用 DOM 节点。有 key 时，Vue 基于 key 判断节点是否可复用，保证列表增删时的正确性和性能。不要用 index 作 key（排序/删除时会导致错误复用）。

🚫 不要解构 reactive 对象

const { name } = reactive({ name: 'Alice' }) 解构后 name 失去响应式。用 toRefs()：const { name } = toRefs(state) 将每个属性转为 ref。或直接使用 ref。

⚠ ref 需要 .value，模板中不需要

在 <script setup> 中访问 ref 需要 count.value，但在 <template> 中自动解包，直接用 {{ count }}。注意 reactive 对象中的 ref 也会自动解包。

1Vue 3 的响应式原理是什么？
使用 Proxy 拦截对象的读写操作。读取时通过 track() 收集依赖（当前渲染函数/effect），修改时通过 trigger() 通知依赖更新。ref 用对象包装原始值实现响应式。相比 Vue 2 的 defineProperty，Proxy 能检测属性增删、数组索引修改。
2ref 和 reactive 的区别？
ref：包装原始值或对象，通过 .value 访问，模板自动解包，推荐用于基础值。reactive：直接代理对象，不需要 .value，不能替换整个对象（会丢失响应式），解构会丢失响应式。推荐：基础值用 ref，对象用 reactive 或 ref({})。
3Vue 组件通信有哪些方式？
① props + emit（父子）；② v-model（父子双向绑定）；③ provide/inject（跨层级）；④ ref + expose（父调子方法）；⑤ Event Bus（mitt，任意组件）；⑥ Pinia/Vuex（全局状态）；⑦ URL 路由参数。
