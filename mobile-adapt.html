移动端适配

移动端屏幕碎片化严重——理解 viewport、rem/vw 方案和 Safe Area，才能让页面在所有设备上正确展示。

1. 核心概念与定义

移动端适配的目标是让同一套代码在不同尺寸、不同 DPR（设备像素比）的移动设备上都能正确显示。核心挑战：屏幕宽度从 320px 到 428px 不等，还有刘海屏、底部安全区域等特殊布局需求。

viewport是移动端适配的基础。移动浏览器有两个视口：布局视口（Layout Viewport）和视觉视口（Visual Viewport）。正确设置 viewport meta 标签是适配的第一步。

主流适配方案：rem + 动态 html font-size（传统方案）和 vw/vh（现代方案）。两者可以配合使用。

2. 关键特性与工作原理

2.1 Viewport Meta 标签

HTML<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">

// 各属性含义：
// width=device-width：布局视口 = 设备宽度（不设置则默认 980px）
// initial-scale=1.0：初始缩放比例
// maximum-scale=1.0：最大缩放比例
// user-scalable=no：禁止缩放（可访问性不好，谨慎使用）

2.2 物理像素、CSS 像素与 DPR

概念说明关系
物理像素设备屏幕的实际像素点硬件决定
CSS 像素CSS 中使用的逻辑像素1 CSS px = DPR × 物理像素
DPR设备像素比 = 物理像素 / CSS 像素window.devicePixelRatio

常见设备 DPR：iPhone 6/7/8 = 2x，iPhone 12/13/14 Pro = 3x，Android 主流 = 2x~3.5x。1px 边框问题：CSS 写 1px，在 2x 屏幕上实际渲染 2 个物理像素，看起来比设计稿粗。

2.3 rem 适配方案

rem（root em）是相对于 html 元素 font-size 的单位。核心思路：JS 根据屏幕宽度动态设置 html 的 font-size，CSS 中使用 rem 单位。

JavaScript// 以 375px 设计稿为基准，1rem = 100px
function setRem() {
  const designWidth = 375;
  const baseFontSize = 100;
  const scale = document.documentElement.clientWidth / designWidth;
  document.documentElement.style.fontSize = baseFontSize * scale + 'px';
}
setRem();
window.addEventListener('resize', setRem);

// 设计稿上 200px 的元素 → 200/100 = 2rem
// 在 375px 屏幕上：2rem = 200px
// 在 750px 屏幕上：2rem = 400px（等比放大）

2.4 vw 适配方案

单位含义示例（375px 屏幕）
1vw视口宽度的 1%3.75px
1vh视口高度的 1%≈ 8.12px
1vminmin(vw, vh)3.75px
1vmaxmax(vw, vh)8.12px

设计稿上 200px 的元素 → 200/375 × 100 = 53.33vw。可用 postcss-px-to-viewport 自动转换。

  bottom: 0;

/* 横屏适配 */

}

4. 常见问题与坑点

rem 和 vw 怎么选？ +

vw 方案更现代，不需要 JS 计算，纯 CSS 即可。但 vw 在超大屏幕上会无限放大，需要 max-width 限制。rem 方案更灵活，可以通过 JS 控制缩放上限。推荐组合：html font-size 用 vw 设置，元素用 rem 单位，兼顾两者优点。

iOS 弹性滚动怎么处理？ +

iOS Safari 默认允许页面弹性滚动（bounce），可能导致固定定位元素随页面移动。解决方案：① overscroll-behavior: none 阻止弹性滚动；② 固定元素用 position: fixed；③ 滚动容器用 -webkit-overflow-scrolling: touch + overflow: auto。

🚫 不要忘记 viewport-fit=cover

iOS 刘海屏适配的前提是 viewport meta 中设置 viewport-fit=cover，否则 env(safe-area-inset-*) 值为 0，安全区域适配不生效。

11px 边框问题怎么解决？
CSS 写 1px，在高清屏上渲染为 2~3 物理像素。方案：① transform scaleY(0.5) 伪元素（推荐）；② box-shadow 模拟；③ viewport 整体缩放（不推荐）；④ border-image SVG；⑤ @media 查询 DPR。
2rem 适配方案的原理？
rem 相对 html font-size。JS 根据屏幕宽度动态设置 html font-size：fontSize = clientWidth / designWidth × baseFontSize。CSS 中所有尺寸用 rem，自动按屏幕宽度等比缩放。设计稿 200px → 200/baseFontSize rem。
