React Hooks

Hooks 是 React 函数组件的灵魂——掌握 useState、useEffect、useCallback、useMemo 和自定义 Hook，是从"能用 React"到"用好 React"的关键。

1. 核心概念与定义

Hooks是 React 16.8 引入的特性，让函数组件能够使用 state、生命周期等能力，无需编写 class。Hooks 本质是一组特殊函数，以 use 开头，只能在函数组件或自定义 Hook 中调用。

Hooks 解决的问题：① 在组件之间复用状态逻辑（替代 HOC 和 render props）；② 将关联的逻辑放在一起（替代生命周期函数的拆分）；③ 让函数组件拥有与 class 相同的能力。

2. 关键特性与工作原理

2.1 核心 Hooks 速查

Hook用途常见场景
useState声明状态表单值、开关、计数器
useEffect副作用处理数据获取、订阅、DOM 操作
useContext读取上下文主题、国际化、全局状态
useReducer复杂状态管理表单、多关联状态
useCallback缓存函数引用优化子组件 re-render
useMemo缓存计算结果昂贵计算、引用稳定
useRef持久引用DOM 引用、存可变值

2.2 useEffect 生命周期对应

Class 生命周期useEffect 等价写法
componentDidMountuseEffect(() => {}, [])
componentDidUpdateuseEffect(() => {})（无依赖数组）
componentWillUnmountuseEffect(() => { return () => {} }, [])
shouldComponentUpdateReact.memo + useMemo/useCallback

2.3 Hooks 规则

💡 两条铁律

1. 只在函数组件和自定义 Hook 的顶层调用 Hooks（不在循环、条件、嵌套函数中）
2. 只在 React 函数组件或自定义 Hook 中调用 Hooks（不在普通 JS 函数中）

原因：React 依靠 Hooks 的调用顺序来匹配对应的 state。如果顺序变化，匹配会错乱导致 Bug。ESLint 规则 react-hooks/rules-of-hooks 可以自动检查。

2.4 闭包陷阱（Stale Closure）

当 useEffect 的闭包捕获了旧值的 state/props，但依赖数组中未包含该值时，effect 中使用的永远是旧值。

JSX// ❌ 闭包陷阱：count 永远是 0
useEffect(() => {
  const timer = setInterval(() => {
    console.log(count); // 始终 0
    setCount(count + 1); // 始终 setCount(0 + 1)
  }, 1000);
  return () => clearInterval(timer);
}, []); // 缺少 count 依赖

// ✅ 方案1：函数式更新
setCount(c => c + 1); // 不依赖外部 count

// ✅ 方案2：useRef 存最新值
const countRef = useRef(count);
countRef.current = count;
// 闭包中使用 countRef.current

3. 代码示例与最佳实践

示例一：useReducer 复杂状态

JSXimport { useReducer } from 'react';

// 适合：多个关联状态、下一个状态依赖前一个
function formReducer(state, action) {
  switch (action.type) {
    case 'SET_FIELD':
      return { ...state, [action.field]: action.value };
    case 'SET_ERRORS':
      return { ...state, errors: action.errors };
    case 'RESET':
      return action.initialState;
    default:
      return state;
  }
}

function useForm(initialValues, validate) {
  const [state, dispatch] = useReducer(formReducer, {
    values: initialValues,
    errors: {},
    touched: {},
  });

  function handleChange(e) {
    const { name, value } = e.target;
    dispatch({ type: 'SET_FIELD', field: name, value });
  }

  function handleSubmit(e) {
    e.preventDefault();
    const errors = validate(state.values);
    dispatch({ type: 'SET_ERRORS', errors });
    if (Object.keys(errors).length === 0) {
      console.log('Submit:', state.values);
    }
  }

  return { ...state, handleChange, handleSubmit };
}

示例二：useCallback 和 useMemo 优化

JSXimport { useState, useCallback, useMemo, memo } from 'react';

// React.memo：浅比较 props，避免不必要的 re-render
const ExpensiveList = memo(function List({ items, onSelect }) {
  console.log('List rendered');
  return (
    <ul>
      {items.map(item => (
        <li key={item.id} onClick={() => onSelect(item.id)}>
          {item.name}
        </li>
      ))}
    </ul>
  );
});

function App() {
  const [keyword, setKeyword] = useState('');
  const [count, setCount] = useState(0);
  const [items] = useState([...]);

  // useMemo：缓存计算结果，依赖不变时不重新计算
  const filteredItems = useMemo(
    () => items.filter(item => item.name.includes(keyword)),
    [items, keyword]
  );

  // useCallback：缓存函数引用，依赖不变时返回同一函数
  const handleSelect = useCallback((id) => {
    console.log('Selected:', id);
  }, []); // 空依赖 → 函数引用永不变化

  return (
    <div>
      <input value={keyword} onChange={e => setKeyword(e.target.value)} />
      <button onClick={() => setCount(c => c + 1)}>{count}</button>
      <ExpensiveList items={filteredItems} onSelect={handleSelect} />
    </div>
  );
}

// 何时使用 useCallback/useMemo：
// 1. 传给 memo 子组件的函数/值 → 用 useCallback/useMemo
// 2. 昂贵的计算 → 用 useMemo
// 3. 作为 useEffect 的依赖 → 用 useCallback/useMemo 稳定引用
// 不要滥用：简单计算和无需稳定的引用不需要优化

示例三：useRef 常见用法

JSXimport { useRef, useEffect, useCallback } from 'react';

function useLatest(value) {
  const ref = useRef(value);
  ref.current = value; // 每次渲染更新
  return ref;
}

function Example() {
  const inputRef = useRef(null);
  const timerRef = useRef(null);
  const renderCount = useRef(0);

  // 1. DOM 引用
  useEffect(() => {
    inputRef.current?.focus(); // 挂载后自动聚焦
  }, []);

  // 2. 存储可变值（不触发 re-render）
  renderCount.current++;

  // 3. 存储 timer ID
  function startTimer() {
    timerRef.current = setInterval(() => {
      console.log('tick');
    }, 1000);
  }
  function stopTimer() {
    clearInterval(timerRef.current);
  }

  // 4. 追踪上一次值
  function usePrevious(value) {
    const ref = useRef();
    useEffect(() => { ref.current = value; });
    return ref.current;
  }

  return <input ref={inputRef} />;
}

示例四：自定义 Hook 模式

JSX// useDebounce：防抖值
function useDebounce(value, delay = 300) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}

// useToggle：开关状态
function useToggle(initial = false) {
  const [value, setValue] = useState(initial);
  const toggle = useCallback(() => setValue(v => !v), []);
  const setTrue = useCallback(() => setValue(true), []);
  const setFalse = useCallback(() => setValue(false), []);
  return { value, toggle, setTrue, setFalse };
}

// 使用
function SearchPage() {
  const [query, setQuery] = useState('');
  const debouncedQuery = useDebounce(query, 500);
  const { value: isOpen, toggle } = useToggle();

  useEffect(() => {
    if (debouncedQuery) {
      // 使用防抖后的值发请求
      fetchResults(debouncedQuery);
    }
  }, [debouncedQuery]);

  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      <button onClick={toggle}>{isOpen ? '关闭' : '打开'}</button>
    </div>
  );
}

示例五：Context + useReducer 全局状态

JSXimport { createContext, useContext, useReducer } from 'react';

// 创建 Context
const AppStateContext = createContext(null);
const AppDispatchContext = createContext(null);

// Reducer
function appReducer(state, action) {
  switch (action.type) {
    case 'SET_USER':
      return { ...state, user: action.payload };
    case 'SET_THEME':
      return { ...state, theme: action.payload };
    case 'LOGOUT':
      return { ...state, user: null };
    default:
      return state;
  }
}

// Provider 组件
function AppProvider({ children }) {
  const [state, dispatch] = useReducer(appReducer, {
    user: null,
    theme: 'light',
  });

  return (
    <AppStateContext.Provider value={state}>
      <AppDispatchContext.Provider value={dispatch}>
        {children}
      </AppDispatchContext.Provider>
    </AppStateContext.Provider>
  );
}

// 自定义 Hook：分离 state 和 dispatch，减少不必要的 re-render
function useAppState() {
  return useContext(AppStateContext);
}
function useAppDispatch() {
  return useContext(AppDispatchContext);
}

// 使用
function Header() {
  const { user } = useAppState(); // 只订阅 user
  const dispatch = useAppDispatch();

  return (
    <header>
      {user ? `Hello, ${user.name}` : '请登录'}
      <button onClick={() => dispatch({ type: 'LOGOUT' })}>退出</button>
    </header>
  );
}

4. 常见问题与坑点

useEffect 和 useLayoutEffect 的区别？ +

useEffect：DOM 更新后异步执行，不阻塞浏览器绘制，适合大多数副作用。useLayoutEffect：DOM 更新后同步执行，阻塞浏览器绘制，适合需要读取布局信息或同步修改 DOM 的场景（如测量元素位置、自动调整样式）。服务端渲染时 useLayoutEffect 会报警告。

什么时候用 useCallback/useMemo？ +

不要为了"优化"而到处加。使用场景：① 传给 memo 子组件的 props（函数用 useCallback，值用 useMemo）；② 作为 useEffect 的依赖（稳定引用避免无限 effect）；③ 计算成本高的值用 useMemo 缓存。简单场景不需要，React 的 diff 本身很快。

React 18 的 useEffect 行为变化？ +

React 18 在严格模式下，开发环境会故意卸载再重新挂载组件，导致 useEffect 执行两次。这是为了帮助发现清理函数的 Bug。生产环境不会执行两次。如果你的 effect 没有正确的清理函数（如未移除事件监听器），这个行为会帮你暴露问题。

🚫 无限 Effect 循环

useEffect(() => { setData(compute()); }, [data]) — effect 修改了自己的依赖，导致无限循环。解决方案：确保 effect 不修改自己的依赖；使用函数式更新 setData(prev => ...)；将计算移到 effect 外部。

⚠ 对象/数组作为依赖

useEffect(() => {}, [obj]) — 每次渲染 obj 是新引用，effect 每次都执行。解决方案：用 useMemo 缓存对象；只依赖需要的具体属性 [obj.id, obj.name]；或使用 useRef 存储不需要触发 effect 的值。

1为什么 Hooks 不能在条件语句中使用？
React 用调用顺序来匹配每个 Hook 调用到对应的 state。如果条件语句中有时调用有时不调用，顺序会变化，导致后续 Hook 匹配到错误的 state。解决方案：将条件判断放在 Hook 内部，而不是包裹 Hook。
2useEffect 的依赖数组为空和不传有什么区别？
空数组 []：仅在挂载和卸载时执行（等同于 componentDidMount + componentWillUnmount）。不传依赖：每次渲染后都执行（等同于 componentDidMount + componentDidUpdate）。传具体依赖：仅在依赖变化时执行。
3如何实现组件的强制刷新？
① useState 设置一个版本号 state，需要刷新时 setVersion(v => v + 1)；② useReducer 的 dispatch({}) 触发 re-render；③ class 组件的 forceUpdate()。不推荐直接修改 state 然后设置回（可能不触发更新）。
