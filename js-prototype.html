原型与继承

JavaScript 使用原型链实现继承，而非传统的类继承。理解原型链的查找机制、class 的语法糖本质，是深入理解 JS 面向对象的关键。

1. 核心概念与定义

JavaScript 的对象系统基于原型（Prototype）。每个对象都有一个内部属性 [[Prototype]]（可通过 __proto__ 或 Object.getPrototypeOf() 访问），指向另一个对象。当访问对象的属性时，如果自身没有，引擎会沿着原型链向上查找。

原型链（Prototype Chain）是由对象通过 [[Prototype]] 串联起来的链式结构，最终指向 null。这是 JavaScript 实现继承和属性共享的核心机制。

class 是 ES6 引入的语法糖，本质上仍然是基于原型的继承。class 写法更清晰，但不改变底层机制。

2. 关键特性与工作原理

2.1 prototype、__proto__ 和 constructor 的关系

属性所在位置指向说明
Func.prototype构造函数原型对象实例共享的方法和属性存放于此
obj.__proto__实例对象构造函数的 prototype非标准属性，推荐用 Object.getPrototypeOf()
Func.prototype.constructor原型对象构造函数本身保证实例能追溯其构造函数

核心公式：实例.__proto__ === 构造函数.prototype，构造函数.prototype.constructor === 构造函数。

2.2 原型链查找流程

text">访问 obj.property 时：
  ① 在 obj 自身属性中查找 → 找到则返回
  ② 在 obj.__proto__（即 Constructor.prototype）中查找 → 找到则返回
  ③ 在 Constructor.prototype.__proto__ 中查找 → ...
  ④ 直到 null → 返回 undefined

原型链终点：Object.prototype.__proto__ === null。

2.3 继承模式演进

模式优点缺点
原型链继承简单引用类型属性共享，无法传参
构造函数继承可传参，避免引用共享方法无法复用，每实例一份
组合继承结合两者优点父构造函数调用两次
寄生组合继承最优传统方案写法复杂
class 继承（ES6）语法简洁，语义清晰本质仍是原型，需理解底层

2.4 class 语法本质

JavaScriptclass Animal {
  // 等价于 Animal 构造函数
  constructor(name) {
    this.name = name; // 实例属性
  }
  // 等价于 Animal.prototype.speak
  speak() {
    console.log(`${this.name} makes a noise.`);
  }
  // 静态方法：等价于 Animal.create
  static create(name) {
    return new Animal(name);
  }
}

// class 的本质验证
typeof Animal;                    // 'function'
Animal.prototype.speak;          // 函数
Object.getOwnPropertyNames(Animal); // ['length', 'name', 'prototype', 'create']

2.5 属性遮蔽（Shadowing）

当实例和原型上有同名属性时，实例属性会遮蔽原型属性。这不会修改原型上的值，而是在实例自身创建了新属性。

JavaScriptfunction Foo() {}
Foo.prototype.value = 10;
const a = new Foo();
const b = new Foo();

a.value = 20; // 在 a 自身创建 value 属性，遮蔽原型
console.log(a.value);  // 20（自身属性）
console.log(b.value);  // 10（原型属性）
console.log(a.hasOwnProperty('value')); // true
console.log(b.hasOwnProperty('value')); // false

3. 代码示例与最佳实践

示例一：ES6 class 继承完整示例

JavaScriptclass Shape {
  constructor(color) {
    this.color = color;
  }
  describe() {
    return `A ${this.color} shape`;
  }
}

class Circle extends Shape {
  constructor(color, radius) {
    super(color); // 必须在 this 之前调用
    this.radius = radius;
  }
  area() {
    return Math.PI * this.radius ** 2;
  }
  describe() {
    return `${super.describe()}, radius: ${this.radius}`;
  }
}

const c = new Circle('red', 5);
console.log(c.describe()); // 'A red shape, radius: 5'
console.log(c.area());     // 78.5398...

// 原型链验证
c instanceof Circle;  // true
c instanceof Shape;   // true
Object.getPrototypeOf(c) === Circle.prototype; // true

示例二：寄生组合继承（ES5 最优方案）

JavaScript/**
 * 寄生组合继承：只调用一次父构造函数
 * 这是 ES5 时代最优的继承方案，class extends 底层类似此实现
 */
function inheritPrototype(SubType, SuperType) {
  // 创建父原型副本
  const prototype = Object.create(SuperType.prototype);
  // 修正 constructor 指向
  prototype.constructor = SubType;
  // 设置子类的原型
  SubType.prototype = prototype;
}

function Person(name) {
  this.name = name;
  this.friends = [];
}
Person.prototype.addFriend = function(friend) {
  this.friends.push(friend);
};

function Student(name, grade) {
  Person.call(this, name); // 借用构造函数（第二次调用）
  this.grade = grade;
}

inheritPrototype(Student, Person);

Student.prototype.introduce = function() {
  return `I'm ${this.name}, grade ${this.grade}`;
};

const s = new Student('Alice', 3);
s.addFriend('Bob');
console.log(s.introduce()); // "I'm Alice, grade 3"

示例三：Object.create 与原型

JavaScript// Object.create(proto) — 创建以 proto 为原型的新对象
const animal = {
  speak() { console.log(`${this.name} speaks`); },
  init(name) {
    this.name = name;
    return this;
  }
};

// 原型式继承
const dog = Object.create(animal).init('Rex');
dog.speak(); // 'Rex speaks'

// Object.create(null) — 无原型对象，适合做纯净的 Map
const cleanMap = Object.create(null);
cleanMap['key'] = 'value';
// 没有 toString、hasOwnProperty 等原型方法
console.log('key' in cleanMap);  // true
console.log(cleanMap.toString);  // undefined

// Object.create 第二参数：定义属性描述符
const obj = Object.create(animal, {
  name: {
    value: 'Cat',
    writable: true,
    enumerable: true,
    configurable: true
  }
});

示例四：判断属性来源

JavaScriptfunction MyClass() {
  this.ownProp = 'I am own';
}
MyClass.prototype.inheritedProp = 'I am inherited';

const obj = new MyClass();

// hasOwnProperty — 是否为自身属性
obj.hasOwnProperty('ownProp');       // true
obj.hasOwnProperty('inheritedProp'); // false

// in 操作符 — 包含原型链
'ownProp' in obj;       // true
'inheritedProp' in obj; // true
'toString' in obj;      // true（来自 Object.prototype）

// for...in — 遍历可枚举属性（含原型链）
for (const key in obj) {
  if (obj.hasOwnProperty(key)) {
    console.log('own:', key); // 'own: ownProp'
  }
}

// Object.keys() — 仅自身可枚举属性
Object.keys(obj); // ['ownProp']

// Object.getOwnPropertyNames() — 仅自身属性（含不可枚举）
Object.getOwnPropertyNames(obj); // ['ownProp']

示例五： mixin 模式（多继承替代）

JavaScript/**
 * JavaScript 不支持多继承，但可通过 mixin 模式混入多个功能
 */
const Serializable = {
  toJSON() {
    return JSON.stringify(this, null, 2);
  },
  fromJSON(json) {
    return Object.assign(Object.create(Object.getPrototypeOf(this)), JSON.parse(json));
  }
};

const Validatable = {
  validate() {
    const errors = [];
    if (!this.name || this.name.trim() === '') {
      errors.push('Name is required');
    }
    return { valid: errors.length === 0, errors };
  }
};

class User {
  constructor(name, email) {
    this.name = name;
    this.email = email;
  }
}

// 混入
Object.assign(User.prototype, Serializable, Validatable);

const user = new User('Alice', 'alice@test.com');
console.log(user.validate()); // { valid: true, errors: [] }
console.log(user.toJSON());   // '{\n  "name": "Alice",\n  "email": "alice@test.com"\n}'

4. 常见问题与坑点

__proto__ 和 prototype 有什么区别？ +

prototype 是构造函数的属性，指向原型对象，用于定义实例共享的方法。__proto__ 是对象的内部属性，指向其构造函数的 prototype。关系：实例.__proto__ === 构造函数.prototype。__proto__ 是非标准属性，推荐使用 Object.getPrototypeOf()。

为什么修改原型上的引用类型会影响所有实例？ +

原型上的引用类型（数组、对象）被所有实例共享。如果实例直接修改引用类型（如 this.arr.push(1)），修改的是原型上的同一个数组。解决方案：引用类型属性在构造函数中初始化（每个实例独立拥有），不要放在原型上。

class 和 function 构造函数有什么区别？ +

class 不会变量提升（有 TDZ）；class 中的方法不可枚举；class 必须用 new 调用（直接调用报错）；class 的 constructor 默认返回 this。本质相同，class 是语法糖，底层仍基于原型链。

🚫 不要在原型上放引用类型

Person.prototype.hobbies = []; 会导致所有实例共享同一个数组！一个实例 push 了一个值，所有实例都能看到。引用类型属性必须在构造函数中创建。

⚠ 重写 prototype 会丢失 constructor

Func.prototype = { method() {} }; 会导致 constructor 指向 Object 而非 Func。修复：Func.prototype.constructor = Func;，或用 Object.defineProperty 定义不可枚举的 constructor。

2如何实现继承？ES5 和 ES6 各怎么写？
ES5 最优方案：寄生组合继承（Object.create 复制父原型 + 借用构造函数传参）。ES6：class + extends + super。class 本质是语法糖，底层仍是原型链。注意 super() 必须在 this 之前调用。
3instanceof 的原理是什么？
instanceof 检查构造函数的 prototype 是否在对象的原型链上。等价于：沿着 obj.__proto__ 向上查找，看是否有等于 Constructor.prototype 的。因此 instanceof 对原始类型返回 false，且跨 iframe 会失效（不同全局环境的 prototype 不同）。
