ES6+ 新特性

ES6（ECMAScript 2015）是 JavaScript 最重要的版本更新，之后的每年发布新标准（ES2016+）。这些特性从根本上改变了 JS 的编写方式，是现代前端开发的基础。

1. 核心概念与定义

ES6+ 不是单一版本，而是从 ES2015 开始持续至今的语法和 API 增强。最重要的特性包括：解构赋值、展开/剩余运算符、模板字符串、箭头函数、Map/Set、Proxy/Reflect、迭代器与生成器等。

这些特性解决了 ES5 时代的痛点：变量提升、回调地狱、缺乏模块化、对象操作不便等。理解这些特性不仅是编码效率的问题，更是读懂现代代码库的前提。

2.4 Proxy 与 Reflect

Proxy 用于创建对象的代理，拦截并自定义基本操作（属性查找、赋值、枚举、函数调用等）。Reflect 提供与 Proxy 拦截器对应的方法，是操作对象的默认行为。

Proxy 拦截器触发时机Reflect 方法
get(target, key)读取属性Reflect.get()
set(target, key, value)设置属性Reflect.set()
has(target, key)key in proxyReflect.has()
deleteProperty(target, key)delete proxy[key]Reflect.deleteProperty()
apply(target, thisArg, args)函数调用Reflect.apply()

2.5 迭代器与生成器

迭代器（Iterator）是实现了 [Symbol.iterator]() 方法和 next() 方法的对象。生成器（Generator）是通过 function* 声明的函数，调用后返回迭代器，yield 暂停执行，next() 恢复执行。

示例三：Proxy 实现响应式

JavaScript/**
 * 简易响应式系统（类似 Vue 3 Reactivity 的核心思路）
 */
function reactive(target) {
  return new Proxy(target, {
    get(obj, key, receiver) {
      // 依赖收集（简化版）
      track(obj, key);
      const result = Reflect.get(obj, key, receiver);
      // 深层响应式：如果值是对象，递归代理
      if (result !== null && typeof result === 'object') {
        return reactive(result);
      }
      return result;
    },
    set(obj, key, value, receiver) {
      const oldValue = Reflect.get(obj, key, receiver);
      const result = Reflect.set(obj, key, value, receiver);
      if (oldValue !== value) {
        // 触发更新
        trigger(obj, key);
      }
      return result;
    }
  });
}

// 简化的依赖管理

function track(target, key) {
  if (effectStack.length) {
    const effect = effectStack[effectStack.length - 1];
    // 记录 effect 依赖 target.key
  }
}
function trigger(target, key) {
  console.log(`属性 ${String(key)} 发生变化`);
}

4. 常见问题与坑点

展开运算符是深拷贝还是浅拷贝？ +

浅拷贝。{ ...obj } 和 [...arr] 只复制第一层。嵌套对象仍然是引用。深拷贝需用 structuredClone() 或 JSON.parse(JSON.stringify()) 或递归实现。

?? 和 || 的区别？ +

?? 仅在 null/undefined 时使用右侧值；|| 在所有 falsy 值（0、''、false、null、undefined、NaN）时使用右侧值。当 0 或 '' 是有效值时，必须用 ?? 而非 ||。

Map 和 WeakMap 的区别？ +

WeakMap 的键必须是对象，且是弱引用——当键对象没有其他引用时，会被 GC 回收。WeakMap 不可迭代、没有 size、没有 clear()。适用场景：为对象关联数据而不阻止回收（如 DOM 元素关联数据、私有属性存储）。

🚫 对象展开顺序与覆盖

{ ...defaults, ...userConfig } 中，后面的属性覆盖前面的。但嵌套对象不会深度合并：{ a: { x: 1 } } 和 { a: { y: 2 } } 合并后 a 是 { y: 2 }，不是 { x: 1, y: 2 }。需要深度合并使用自定义函数或 lodash.merge。

⚠ Proxy 不能代理原始值

Proxy 只能代理对象。若要代理原始值（如数字、字符串），需用对象包装或使用 Vue 的 ref 方案：const count = reactive({ value: 0 })。Vue 3 的 ref 正是为此设计。

1展开运算符和 Object.assign 有什么区别？
展开运算符 { ...a } 和 Object.assign({}, a) 效果基本相同，都是浅拷贝。区别：① Object.assign 会触发 setter，展开不会；② Object.assign 可以修改目标对象（不传空对象时）；③ 展开运算符不能复制原型链属性。
2Proxy 和 Object.defineProperty 的区别？
Proxy：代理整个对象，可以拦截属性访问/删除/枚举/函数调用等 13 种操作；可以检测新增属性；默认不代理嵌套对象。Object.defineProperty：只能劫持已有属性；无法检测新增/删除属性（Vue 2 需要 $set/$delete）；需要遍历属性逐个定义。Vue 3 用 Proxy 替代了 defineProperty。
3for...of 和 for...in 的区别？
for...of 遍历可迭代对象的值（Array、Map、Set、String、Generator），不遍历原型链。for...in 遍历对象的可枚举属性键（含原型链），不适合数组（遍历的是索引字符串）。数组和 Map/Set 用 for...of，普通对象用 for...in 或 Object.keys()。
