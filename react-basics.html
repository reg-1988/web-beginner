React 基础

React 用声明式的方式构建 UI——理解 JSX、组件、Props/State 和生命周期，是掌握 React 生态的第一步。

1. 核心概念与定义

React是 Facebook 开源的 UI 构建库，核心思想是 UI = f(state)——UI 是状态的函数映射。React 负责"声明式"地描述 UI 应该是什么样，框架负责高效地更新 DOM。

React 的三大核心理念：组件化（UI 拆分为独立、可复用的组件）、声明式（描述结果而非过程）、单向数据流（数据从父组件通过 props 向下流动，子组件通过回调向上通信）。

JSX是 JavaScript 的语法扩展，看起来像 HTML 但本质是 JavaScript。const el = <h1>Hello</h1> 编译后是 React.createElement('h1', null, 'Hello')。

3. 代码示例与最佳实践

示例一：函数组件与 useState

JSXimport { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(c => c + 1)}>+1</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}

// useState 注意事项：
// 1. 更新是异步的，不能依赖更新后的值
// 2. 使用函数式更新获取最新值：setCount(c => c + 1)
// 3. 对象/数组必须创建新引用：setData({...data, key: newValue})
// 4. 初始值只用在首次渲染，后续忽略（可用惰性初始化）

示例二：表单处理

JSXimport { useState } from 'react';

function LoginForm() {
  const [form, setForm] = useState({ email: '', password: '' });
  const [errors, setErrors] = useState({});

  function handleChange(e) {
    const { name, value } = e.target;
    // 创建新对象，不要直接修改
    setForm(prev => ({ ...prev, [name]: value }));
    // 清除对应错误
    if (errors[name]) {
      setErrors(prev => ({ ...prev, [name]: '' }));
    }
  }

  function handleSubmit(e) {
    e.preventDefault();
    const newErrors = {};
    if (!form.email) newErrors.email = '请输入邮箱';
    if (!form.password) newErrors.password = '请输入密码';
    if (Object.keys(newErrors).length) {
      setErrors(newErrors);
      return;
    }
    console.log('Submit:', form);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="email"
        value={form.email}
        onChange={handleChange}
        placeholder="邮箱"
      />
      {errors.email && <span className="error">{errors.email}</span>}
      <input
        name="password"
        type="password"
        value={form.password}
        onChange={handleChange}
      />
      {errors.password && <span className="error">{errors.password}</span>}
      <button type="submit">登录</button>
    </form>
  );
}

示例三：组件组合与 Props

JSX// 容器组件：管理状态和逻辑
function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('/api/users')
      .then(r => r.json())
      .then(data => { setUsers(data); setLoading(false); });
  }, []);

  function handleDelete(id) {
    setUsers(prev => prev.filter(u => u.id !== id));
  }

  if (loading) return <Loading />;

  return (
    <ul>
      {users.map(user => (
        <UserItem
          key={user.id}
          user={user}
          onDelete={handleDelete}
        />
      ))}
    </ul>
  );
}

// 展示组件：接收 props，纯 UI
function UserItem({ user, onDelete }) {
  return (
    <li>
      <span>{user.name}</span>
      <button onClick={() => onDelete(user.id)}>删除</button>
    </li>
  );
}

// children prop：组合模式
function Card({ title, children }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <div className="card-body">{children}</div>
    </div>
  );
}

示例四：useEffect 数据获取

JSXimport { useState, useEffect } from 'react';

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let cancelled = false; // 防止竞态条件

    async function fetchUser() {
      setLoading(true);
      setError(null);
      try {
        const res = await fetch(`/api/users/${userId}`);
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        if (!cancelled) setUser(data);
      } catch (err) {
        if (!cancelled) setError(err.message);
      } finally {
        if (!cancelled) setLoading(false);
      }
    }

    fetchUser();

    // 清理函数：组件卸载或 userId 变化时取消
    return () => { cancelled = true; };
  }, [userId]); // 依赖数组：userId 变化时重新执行

  if (loading) return <p>加载中...</p>;
  if (error) return <p>错误: {error}</p>;
  if (!user) return null;

  return <div>{user.name}</div>;
}

示例五：自定义 Hook

JSX/**
 * 通用数据获取 Hook
 * 遵循：以 use 开头、调用其他 Hook、返回状态
 */
function useFetch(url, options = {}) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController();

    async function fetchData() {
      setLoading(true);
      try {
        const res = await fetch(url, {
          ...options,
          signal: controller.signal,
        });
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const json = await res.json();
        setData(json);
        setError(null);
      } catch (err) {
        if (err.name !== 'AbortError') {
          setError(err.message);
        }
      } finally {
        setLoading(false);
      }
    }

    fetchData();
    return () => controller.abort();
  }, [url]);

  return { data, loading, error };
}

// 使用
function UserPage({ id }) {
  const { data: user, loading, error } = useFetch(`/api/users/${id}`);

  if (loading) return <Loading />;
  if (error) return <Error message={error} />;
  return <UserCard user={user} />;
}

4. 常见问题与坑点

为什么 State 更新后读不到新值？ +

setState 是异步的，调用后 state 不会立即更新。setCount(1); console.log(count); 仍打印旧值。获取最新值：① 在 setState 的函数式更新中获取；② 使用 useEffect 监听 state 变化；③ 使用 useRef 存储最新值。

为什么不能在循环/条件中使用 Hooks？ +

React 依赖 Hooks 的调用顺序来匹配 state。如果顺序变化（如条件中跳过某个 Hook），后续 Hook 的匹配会错乱。这是 Hooks 的核心规则：只在顶层调用，不在循环/条件/嵌套函数中调用。

useEffect 的依赖数组怎么确定？ +

规则：effect 中使用的所有响应式值（props、state、派生值）都必须列入依赖。ESLint 的 exhaustive-deps 规则可以自动检测遗漏。技巧：如果只想在挂载时执行，确保依赖数组为 []；如果某个值不需要触发重新执行，用 useRef 存储。

🚫 直接修改 State

state.push(item) 或 state.key = value 是直接修改，React 检测不到变化，不会重新渲染。必须创建新引用：setState([...state, item])、setState({...state, key: value})。

⚠ useEffect 缺少依赖导致闭包陷阱

useEffect 中引用的 state/props 如果不在依赖数组中，会使用闭包中的旧值（stale closure）。解决方案：确保依赖数组完整，或使用 useRef 存储最新值：const latestRef = useRef(value); latestRef.current = value;

1React 组件的渲染流程？
触发渲染（setState/props 变化/forceUpdate）→ 渲染阶段（执行组件函数，生成虚拟 DOM / React Element）→ 协调阶段（Reconciliation，对比新旧虚拟 DOM，计算最小变更）→ 提交阶段（Commit，将变更应用到真实 DOM）。渲染和协调是可中断的，提交是不可中断的。
2受控组件和非受控组件的区别？
受控组件：表单值由 React state 控制，onChange 更新 state，value 绑定 state。数据流：state → UI → state（单向）。非受控组件：表单值由 DOM 自身管理，通过 ref 获取值。受控组件更可控，推荐使用。非受控组件适合集成非 React 代码或简单场景。
3React 和 Vue 的核心区别？
理念：React 是 UI 库（JSX = JS 优先），Vue 是渐进式框架（模板 = HTML 优先）。响应式：React 不可变数据 + setState 触发，Vue Proxy 自动追踪。写法：React JSX/函数式，Vue 模板/声明式。状态管理：React 手动（useState/useReducer），Vue 自动（ref/reactive）。学习曲线：React 更灵活但需理解更多概念，Vue 约定优于配置上手更快。
