Vue Router

Vue Router 是 Vue.js 的官方路由管理器——掌握路由配置、导航守卫、懒加载和动态路由，是构建单页应用的关键。

1. 核心概念与定义

Vue Router是 Vue.js 的官方路由，用于构建单页应用（SPA）。它通过History API或Hash 模式管理 URL，将 URL 路径映射到组件，实现无刷新的页面切换。

路由的核心概念：路由映射（URL → 组件）、嵌套路由（父路由包含子路由）、导航守卫（路由切换时的拦截和控制）、动态路由（参数化路径）、懒加载（按需加载组件）。

2.3 路由元信息（Meta）

每个路由可以携带 meta 信息，用于导航守卫中的逻辑判断。TypeScript 中可通过 RouteMeta 扩展类型。

TypeScript// 扩展路由元信息类型
declare module 'vue-router' {
  interface RouteMeta {
    requiresAuth?: boolean;  // 是否需要登录
    title?: string;          // 页面标题
    permissions?: string[];  // 所需权限
    keepAlive?: boolean;     // 是否缓存组件
  }
}

  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
  scrollBehavior(to, from, savedPosition) {
    return savedPosition || { top: 0 }; // 滚动到顶部或恢复位置
  },
});

export default router;

示例二：全局导航守卫

JavaScript// router/guards.js
import { useAuthStore } from '@/stores/auth';

export function setupGuards(router) {
  const auth = useAuthStore();

  // 全局前置守卫
  router.beforeEach(async (to, from) => {
    // 进度条
    NProgress.start();

    // 登录检查
    if (to.meta.requiresAuth && !auth.isLoggedIn) {
      return {
        name: 'Login',
        query: { redirect: to.fullPath }, // 保存目标路径
      };
    }

    // 权限检查
    if (to.meta.permissions?.length) {
      const hasPermission = to.meta.permissions.every(
        p => auth.permissions.includes(p)
      );
      if (!hasPermission) return { name: 'Forbidden' };
    }

    // 页面标题
    document.title = to.meta.title
      ? `${to.meta.title} - MyApp`
      : 'MyApp';
  });

  // 全局后置钩子
  router.afterEach(() => {
    NProgress.done();
  });
}

示例三：动态路由与权限路由

JavaScript// 根据用户角色动态添加路由
export function addDynamicRoutes(router, userRole) {
  const roleRoutes = {
    admin: [
      {
        path: '/admin',
        component: () => import('@/layouts/AdminLayout.vue'),
        children: [
          { path: 'settings', component: () => import('@/views/admin/Settings.vue') },
          { path: 'logs', component: () => import('@/views/admin/Logs.vue') },
        ],
      },
    ],
    editor: [
      {
        path: '/editor',
        component: () => import('@/views/EditorDashboard.vue'),
      },
    ],
  };

  const routes = roleRoutes[userRole] || [];
  routes.forEach(route => {
    router.addRoute(route); // 动态添加路由
  });
}

// 登录后添加路由
async function login(credentials) {
  const { role } = await authApi.login(credentials);

  router.push('/'); // 跳转到首页
}

示例五：页面数据预取

JavaScript// 方案一：导航守卫中预取数据
router.beforeResolve(async (to) => {
  // 收集需要预取数据的路由组件
  const matched = to.matched.filter(
    record => record.meta?.preload
  );

  // 并行预取
  await Promise.all(
    matched.map(record => {
      if (record.meta.preload) {
        return record.meta.preload(to.params);
      }
    })
  );
});

4. 常见问题与坑点

History 模式 404 问题怎么解决？ +

History 模式下刷新页面，服务器会查找对应文件，找不到返回 404。解决方案：配置服务器将所有路径回退到 index.html。Nginx：try_files $uri $uri/ /index.html;。Express：app.get('*', (req, res) => res.sendFile('index.html'))。

路由懒加载 vs 全量加载？ +

懒加载（() => import('./View.vue')）将组件拆分为独立 chunk，按需加载，减小首屏体积。全量加载将所有组件打包到一个文件，首屏加载慢但后续切换无网络请求。推荐：首屏必需的路由全量加载，其他路由懒加载。

如何实现路由缓存（KeepAlive）？ +

用 <keep-alive> 包裹 <router-view>，通过 include/exclude 控制缓存组件。设置 meta.keepAlive 标记需要缓存的路由。注意：缓存组件不会重新触发 setup/mounted，使用 onActivated/onDeactivated 代替。缓存过多组件会占用内存。

🚫 动态路由刷新丢失

通过 router.addRoute() 添加的动态路由在页面刷新后会丢失。必须在路由初始化时重新添加。解决方案：在 beforeEach 守卫中检查是否已添加动态路由，未添加则从服务端获取权限后重新 addRoute。

⚠ 避免在导航守卫中直接修改 DOM

导航守卫中不应该操作 DOM（此时组件可能还未挂载）。需要 DOM 操作的逻辑放在组件的 onMounted 或 onActivated 中。守卫只做逻辑判断（权限检查、数据预取）。

1Hash 模式和 History 模式有什么区别？
Hash：URL 带 #，通过 hashchange 事件监听，不需要服务器配置，SEO 不友好。History：URL 无 #，使用 pushState/replaceState，需要服务器配置回退到 index.html，SEO 友好。生产环境推荐 History 模式。
2如何实现路由权限控制？
① 全局前置守卫 router.beforeEach 检查 meta.requiresAuth；② 白名单路由（登录页等）直接放行；③ 未登录跳转登录页并保存目标路径；④ 登录后根据角色动态添加路由（router.addRoute）；⑤ 路由独享守卫 beforeEnter 做精细控制。
3Vue Router 懒加载的原理？
使用动态 import() 语法：() => import('./View.vue')。Webpack/Vite 将每个动态 import 拆分为独立 chunk 文件。路由切换时浏览器按需下载对应 chunk。结合 Webpack Magic Comments 可命名 chunk：() => import(/* webpackChunkName: "about" */ './About.vue')。
