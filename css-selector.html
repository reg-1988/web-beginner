CSS 选择器与优先级

选择器是 CSS 的灵魂——它决定了样式作用于谁；优先级是 CSS 的规则——它决定了当冲突时谁说了算。

1. 核心概念与定义

CSS 选择器是 CSS 规则的第一部分，用于指定样式要应用到 HTML 文档中的哪些元素。选择器可以是简单的元素名（如 p），也可以是复杂的组合表达式（如 .card:hover .title::after）。CSS 的强大之处在于其选择器体系，它提供了从简单到复杂的多种匹配方式，让开发者可以精确地定位到任何想要样式化的元素。

CSS 优先级（Specificity）是浏览器决定当多条 CSS 规则作用于同一元素同一属性时，哪条规则最终生效的算法。优先级通过一个四位数字来计算，不同类型的选择器贡献不同的权重。理解优先级是写出可预测、可维护 CSS 的关键——不知道优先级的开发者要么过度依赖 !important，要么陷入选择器优先级"军备竞赛"的泥潭。

选择器和优先级的关系密不可分：选择器越精确（通常意味着越复杂），其优先级权重越高。但这不意味着应该追求高优先级——恰恰相反，最佳实践是保持选择器低优先级、低特异性，通过 HTML 结构和命名约定来组织样式，而非依赖优先级覆盖。这一理念催生了 BEM、ITCSS、CSS Modules 等方法论。

2. 关键特性与工作原理

2.1 选择器类型全览

ID 选择器#header匹配 id 属性0,1,0,0

2.2 优先级计算规则

优先级用一个四位数字 (a, b, c, d) 表示，从左到右权重递减：

  • a：内联样式（style 属性），值为 1 或 0
  • b：ID 选择器的数量
  • c：类选择器、属性选择器、伪类的数量
  • d：类型选择器、伪元素的数量
ℹ 优先级计算示例

#nav .item a:hover → (0, 1, 2, 1)：0个内联 + 1个ID + 2个类/伪类(.item, :hover) + 1个类型(a)

div.card::before → (0, 0, 1, 2)：0个内联 + 0个ID + 1个类(.card) + 2个类型/伪元素(div, ::before)

* { } → (0, 0, 0, 0)：通配选择器不贡献优先级

比较规则：从左到右逐位比较，左侧位胜出则整体胜出。(0,1,0,0) 永远大于 (0,0,99,99)——一个 ID 选择器的优先级高于任意数量的类选择器。

2.3 层叠规则（The Cascade）

当优先级相同时，CSS 通过层叠规则决定最终生效的样式：

  1. 来源与重要性（从低到高）：用户代理样式 → 用户样式 → 作者样式 → 作者 !important → 用户 !important → 用户代理 !important
  2. 优先级（Specificity）：同来源时，优先级高的胜出
  3. 源码顺序：同来源同优先级时，后声明的覆盖先声明的
🚫 !important 是最后手段

!important 会将声明提升到最高优先级层级，破坏正常的层叠规则。一旦使用 !important，覆盖它就需要更高优先级的 !important，形成恶性循环。只在极少数情况下使用：覆盖第三方库样式、用户代理样式重置、紧急修复（但应尽快重构）。

2.4 CSS 继承

某些 CSS 属性在父元素上设置后，子元素会自动继承这些值，无需显式声明。可继承的属性主要与文本相关：color、font-family、font-size、font-weight、line-height、text-align、visibility、cursor 等。不继承的属性：border、margin、padding、background、width、height 等。

可以用 inherit 关键字强制继承，initial 重置为初始值，unset 对可继承属性等同于 inherit、对不可继承属性等同于 initial，revert 回退到浏览器默认样式。

2.5 现代 CSS 选择器

选择器说明示例
:is()匹配列表中的任意选择器，不增加优先级:is(h1, h2, h3) { }
:where()同 :is()，但优先级为 0:where(.card) { }
:not()排除匹配的元素:not(.disabled) { }
:has()父选择器——匹配包含指定后代的元素.card:has(img) { }
:nth-child(an+b)按位置匹配子元素li:nth-child(2n+1) { }
:nth-of-type()按同类型位置匹配p:nth-of-type(2) { }
💡 :is() vs :where() 的区别

功能完全相同，唯一区别是优先级：:is() 取参数列表中最高优先级，:where() 优先级始终为 0。推荐：当你需要保持低优先级以便覆盖时用 :where()（如 CSS Reset、组件库默认样式）；当你需要正常的优先级匹配时用 :is()。

2.6 CSS 自定义属性（CSS Variables）

CSS 自定义属性（也称 CSS 变量）使用 -- 前缀定义，用 var() 引用。与预处理器变量不同，CSS 变量是运行时的，参与层叠和继承：

CSS:root {
  --color-primary: #2563eb;
  --spacing-md: 16px;
}

.button {
  background: var(--color-primary);
  padding: var(--spacing-md);
}

/* CSS 变量参与继承和优先级 */
.card {
  --color-primary: #7c3aed;  /* 局部覆盖 */
}
.card .button {
  background: var(--color-primary);  /* 使用覆盖后的值 */
}

3. 代码示例与最佳实践

示例一：优先级计算实战

CSS/* === 优先级计算练习 === */

/* (0, 0, 0, 1) - 一个类型选择器 */
p { color: black; }

/* (0, 0, 1, 0) - 一个类选择器，优先级高于上面的 p */
.text { color: gray; }

/* (0, 0, 1, 1) - 一个类型 + 一个类，优先级更高 */
p.text { color: blue; }

/* (0, 1, 0, 0) - 一个 ID，优先级最高 */
#intro { color: red; }

/* (0, 1, 0, 1) - ID + 类型 */
#intro p { color: green; }

/* (1, 0, 0, 0) - 内联样式，优先级最高（除了 !important） */
/* <p style="color: purple;"> */

/* !important 胜过一切同来源规则 */
p { color: orange !important; }

示例二：现代选择器实践

CSS/* === :is() 简化重复选择器 === */
/* 之前：冗长重复 */
h1 a, h2 a, h3 a, h4 a, h5 a, h6 a {
  color: #2563eb;
  text-decoration: none;
}

/* 之后：简洁 */
:is(h1, h2, h3, h4, h5, h6) a {
  color: #2563eb;
  text-decoration: none;
}

/* === :where() 实现低优先级默认样式 === */
:where(.btn) {
  padding: 8px 16px;
  border: 1px solid #e2e8f0;
  border-radius: 6px;
  background: #fff;
  cursor: pointer;
}

/* 任何选择器都能轻松覆盖 :where 的样式 */
.btn-primary {
  background: #2563eb;  /* 优先级 (0,0,1,0) > :where 的 (0,0,0,0) */
  color: white;
}

/* === :has() 父选择器 === */
/* 只包含图片的卡片样式不同 */
.card:has(img) {
  padding: 0;  /* 图片卡片无内边距 */
}
.card:not(:has(img)) {
  padding: 24px;  /* 文本卡片有内边距 */
}

/* 表单项有错误时的样式 */
.form-group:has(.error-message) {
  border-color: #ef4444;
}
.form-group:has(.error-message) label {
  color: #ef4444;
}

/* === :not() 排除选择器 === */
/* 所有列表项，除了最后一个 */
nav li:not(:last-child) {
  margin-right: 16px;
}

/* 所有 input，除了 submit 类型 */
input:not([type="submit"]):not([type="checkbox"]):not([type="radio"]) {
  width: 100%;
  padding: 8px 12px;
}

示例三：BEM 命名与低优先级策略

CSS/* === BEM 命名规范：保持低优先级 === */

/* Block：卡片组件 */
.card {
  background: #fff;
  border: 1px solid #e2e8f0;
  border-radius: 10px;

}

.card__footer {
  margin-top: 16px;
  padding-top: 12px;
  border-top: 1px solid #e2e8f0;

/* Modifier：变体 */

示例五：选择器性能优化

CSS/* === CSS 选择器性能最佳实践 === */

/* ❌ 避免过深嵌套（浏览器从右到左匹配） */
/* 浏览器先找所有 a，再筛在 .nav 下的，再筛在 header 下的 */
header .nav ul li a {
  color: #2563eb;
}

/* ✅ 直接用类名，减少匹配层级 */
.nav-link {
  color: #2563eb;
}

/* ❌ 避免通配选择器做后代 */
.container * {
  box-sizing: border-box;
}

/* ✅ 使用具体选择器或全局设置 */
*, *::before, *::after {
  box-sizing: border-box;
}

/* ❌ 避免标签限定类选择器（多余的类型选择器增加匹配开销） */
div.container { }

/* ✅ 直接使用类名 */
.container { }

/* ✅ 现代 CSS 的层叠层（@layer）控制优先级 */
@layer reset, base, components, utilities;

@layer reset {
  * { margin: 0; padding: 0; box-sizing: border-box; }
}

@layer base {
  body { font-family: sans-serif; line-height: 1.6; }
  a { color: #2563eb; }
}

@layer components {
  .btn { padding: 8px 16px; border-radius: 6px; }
}

@layer utilities {
  .text-center { text-align: center; }
  .mt-4 { margin-top: 16px; }
}

/* 后声明的 layer 优先级更高：utilities > components > base > reset
   同 layer 内按正常优先级规则 */

4. 常见问题与坑点

为什么我修改了样式但不生效？ +

最常见的原因是优先级被覆盖。排查步骤：① 打开 DevTools → Elements → Styles 面板；② 看你的样式是否被划线（表示被覆盖）；③ 查看覆盖它的选择器的优先级；④ 检查是否有 !important 或内联样式。解决：不要直接加 !important，而是提升选择器优先级或重构选择器结构。

:nth-child(n) 和 :nth-of-type(n) 有什么区别？ +

:nth-child(n) 计算所有兄弟元素中的位置，不考虑类型。例如 p:nth-child(2) 匹配的是"作为第二个子元素的 p"，如果第二个子元素不是 p 则不匹配。:nth-of-type(n) 只计算同类型兄弟元素中的位置。p:nth-of-type(2) 匹配"所有 p 元素中的第二个"，不管前面有多少其他类型的元素。

CSS 选择器是从左到右还是从右到左匹配的？ +

浏览器从右到左匹配 CSS 选择器。例如 .nav li a，浏览器先找页面中所有 a 元素，然后检查是否有 li 祖先，再检查是否有 .nav 祖先。这种匹配方式使得深层嵌套的选择器性能较差，因为浏览器需要从大量右端元素开始逐步验证。这也是为什么推荐使用短而直接的选择器。

🚫 避免选择器优先级"军备竞赛"

当两个选择器竞争同一属性时，开发者有时会不断增加选择器嵌套深度来提高优先级：#nav .item a → #nav .list .item a → #nav .list .item a:hover。这会导致样式越来越难以覆盖和维护。正确做法：使用 BEM 等方法论保持选择器扁平，用 CSS 变量和 @layer 管理优先级。

💡 DevTools 中查看优先级

Chrome DevTools 的 Styles 面板中，样式按优先级从高到低排列。被覆盖的样式会被划线。点击选择器可以看到它的优先级计算值。这是排查样式冲突最有效的工具。

面试题

1CSS 优先级是如何计算的？
优先级用四位数字 (a,b,c,d) 表示：a=内联样式(1/0)、b=ID选择器数量、c=类/属性/伪类数量、d=类型/伪元素数量。比较时从左到右逐位比较。通配符 * 不贡献优先级。:not() 和 :has() 本身不计入优先级，但其参数中的选择器计入。:where() 优先级始终为 0。
2:is()、:where()、:has() 各自的用途和区别？
:is() 匹配参数列表中任意选择器，优先级取参数中最高的。:where() 功能相同但优先级始终为 0，适合做低优先级默认样式。:has() 是"父选择器"，匹配包含指定后代/兄弟的元素，如 a:has(> img) 匹配包含直接子图片的链接。优先级：:is() 按参数计算，:where() 为 0，:has() 按参数计算。
3CSS 选择器是从哪个方向开始匹配的？为什么？
从右到左。浏览器先匹配选择器最右端的关键选择器（key selector），然后逐级向上验证祖先/兄弟关系。这种策略效率更高：如果从左到右，浏览器需要遍历所有匹配的祖先元素的后代，数量可能非常大；从右到左则只需要验证每个候选元素的祖先链，通常候选元素数量远少于祖先的后代总数。
