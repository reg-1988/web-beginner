JavaScript初级

数据类型与类型转换

JavaScript 的类型系统灵活但隐秘，理解原始类型与引用类型的本质区别、掌握隐式转换的规则，是避免 Bug 和通过面试的第一关。

1. 核心概念与定义

JavaScript 是一门动态类型（运行时确定类型）弱类型（自动隐式转换）语言。它有 8 种数据类型：7 种原始类型（Primitive）和 1 种引用类型（Object）。

原始类型的值是不可变的（Immutable），变量存储的是值本身；引用类型的值是可变的（Mutable），变量存储的是指向内存中对象的引用地址。这是理解 JavaScript 赋值、传参、比较的基础。

类型转换分为显式转换（开发者主动调用转换函数）和隐式转换（引擎在运算时自动转换）。隐式转换规则复杂，是 Bug 和面试题的重灾区。

💡 关键理解

原始类型的"不可变"指值本身不可变。字符串方法返回新字符串，原字符串不变：'abc'.toUpperCase() 返回 'ABC'，但原变量不变。引用类型赋值后修改会影响所有引用。

3. 代码示例与最佳实践

示例一：原始类型与引用类型的区别

JavaScript// 原始类型 —— 赋值拷贝值
let a = 10;
let b = a;    // b 得到 a 的值的副本
b = 20;
console.log(a); // 10（a 不受影响）

// 引用类型 —— 赋值拷贝引用
let obj1 = { name: 'Alice' };
let obj2 = obj1; // obj2 指向同一个对象
obj2.name = 'Bob';
console.log(obj1.name); // 'Bob'（obj1 被影响了）

// 函数参数同理
function modify(obj) {
  obj.age = 25; // 修改会影响外部
  obj = { name: 'New' }; // 重新赋值不影响外部
}
let person = { name: 'Alice' };
modify(person);
console.log(person); // { name: 'Alice', age: 25 }

示例二：精确的类型判断工具函数

JavaScript/**
 * 精确判断数据类型
 * @param {*} value - 任意值
 * @returns {string} 类型字符串，如 'Array', 'Null', 'Object' 等
 */
function getType(value) {
  return Object.prototype.toString.call(value).slice(8, -1);
}

// 测试
getType(null);           // 'Null'
getType(undefined);      // 'Undefined'
getType([1, 2]);         // 'Array'
getType(() => {});       // 'Function'
getType(new Date());     // 'Date'
getType(/regex/);        // 'RegExp'
getType({});             // 'Object'
getType(42);             // 'Number'
getType('hello');        // 'String'
getType(Symbol('id'));   // 'Symbol'
getType(10n);            // 'BigInt'

JavaScript// ========== 转字符串 ==========

示例四：经典隐式转换面试题解析

JavaScript// 题目1：[] == ![]
// 步骤：![] → false（[]是truthy，取反为false）
//       [] == false → '' == 0（对象→原始值→数字）
//       → 0 == 0 → true
console.log([] == ![]); // true

// 题目2：{} + []
// 在控制台直接执行，{}被当作空代码块，+[] → 0
// 在表达式中，({}) + [] → '[object Object]'
console.log(({}) + []); // '[object Object]'

// 题目3：'1' + 2 + 3  vs  1 + 2 + '3'
console.log('1' + 2 + 3);  // '123'（从左到右，遇到字符串后续全拼接）
console.log(1 + 2 + '3');  // '33'（先算1+2=3，再拼接'3'）

// 题目4：== 的陷阱
console.log(null == 0);       // false（null 只与 undefined 互等）
console.log(null == undefined); // true
console.log(undefined == 0);   // false

// 最佳实践：始终用 === 避免这些问题
console.log(null === undefined); // false

示例五：深拷贝实现（处理引用类型）

JavaScript/**
 * 简易深拷贝（处理对象、数组、原始类型）
 * 注意：不支持 Function、Date、RegExp、循环引用等
 */
function deepClone(obj) {
  // 原始类型和 null 直接返回
  if (obj === null || typeof obj !== 'object') return obj;

  // 数组处理
  if (Array.isArray(obj)) {
    return obj.map(item => deepClone(item));
  }

  // 普通对象
  const cloned = {};
  for (const key of Object.keys(obj)) {
    cloned[key] = deepClone(obj[key]);
  }
  return cloned;
}

// 生产环境推荐使用 structuredClone（ES2022）
// const copy = structuredClone(original);

// 使用示例
const original = {
  name: 'Alice',
  hobbies: ['reading', 'coding'],
  address: { city: 'Beijing' }
};
const copy = deepClone(original);
copy.hobbies.push('gaming');
console.log(original.hobbies); // ['reading', 'coding']（不受影响）

4. 常见问题与坑点

为什么 typeof null === 'object'？ +

历史遗留问题。JS 第一版中，值以 32 位存储，前 3 位表示类型标记。对象的前三位是 000，而 null 的全部位都是 0，所以 typeof 误判为 "object"。这是一个已知的 Bug，但为了向后兼容无法修复。

0.1 + 0.2 !== 0.3 怎么解决？ +

IEEE 754 双精度浮点数精度问题。解决方案：① 使用 toFixed 后转数字：+(0.1 + 0.2).toFixed(10)；② 使用误差容限：Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON；③ 涉及金额时使用分（整数）计算或第三方库如 decimal.js。

NaN !== NaN，怎么判断 NaN？ +

NaN 是 JS 中唯一不等于自身的值。判断方法：① Number.isNaN(x)（推荐，只有 NaN 返回 true）；② Object.is(x, NaN)；③ x !== x（老式写法）。注意 isNaN('abc') 返回 true（会先转数字），而 Number.isNaN('abc') 返回 false。

🚫 永远不要使用 == 比较不同类型

== 的隐式转换规则极其复杂且反直觉，如 [] == ![] 为 true、[] == false 为 true、'' == 0 为 true。始终使用 === 进行严格比较，唯一例外是 null == undefined 用于同时判断两者。

⚠ 对象作为 Map 键的陷阱

对象的键会被隐式转为字符串：const obj = {}; obj[1] = 'a'; obj['1'] 得到 'a'（数字 1 被转成了字符串）。如果需要任意类型的键，使用 Map。

1JavaScript 有哪些数据类型？它们的区别是什么？
8 种类型：7 原始（Number、String、Boolean、undefined、null、Symbol、BigInt）+ 1 引用（Object）。核心区别：原始类型值不可变，按值存储和比较；引用类型值可变，按引用存储和比较，赋值/传参是浅拷贝。
2== 和 === 的区别？
== 宽松相等会进行隐式类型转换后比较，规则复杂；=== 严格相等不转换类型，类型不同直接 false。建议始终用 ===。唯一推荐用 == 的场景：value == null 等价于 value === null || value === undefined。
3如何准确判断一个变量的类型？
typeof 判断原始类型（注意 null 是 "object"）；Array.isArray() 判断数组；Object.prototype.toString.call(x) 精确判断所有类型（返回 '[object Type]'）；instanceof 检测原型链但跨 iframe 失效。综合使用以上方法。
