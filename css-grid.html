Grid 布局

CSS Grid 是真正的二维布局系统——用行列定义网格，精确定位每个元素，让复杂布局变得简单直观。

1. 核心概念与定义

CSS Grid Layout是 CSS 提供的二维布局系统，允许开发者同时在行和列两个维度上控制元素的排列。与 Flexbox 的一维布局不同，Grid 可以定义一个由行和列组成的网格，然后将元素精确放置到网格的指定位置上。

Grid 的核心思想是布局先行：先定义网格的结构（多少行、多少列、间距多大），再将内容填入网格。这与传统的内容驱动布局（内容决定位置）形成对比。Grid 特别适合页面级别的布局——头部、侧栏、主内容区、底部这些区块的排列，用 Grid 只需几行 CSS 就能完成。

Grid 与 Flexbox 不是替代关系，而是互补关系。Grid 擅长二维的整体布局规划，Flexbox 擅长一维的组件内部排列。最佳实践是：Grid 搭骨架，Flexbox 做细节。

2.3 fr 单位与 repeat()

fr（fraction）是 Grid 特有的弹性长度单位，表示可用空间的一个等份。1fr 1fr 1fr 将空间三等分。1fr 2fr 则第二列是第一列的两倍。fr 与固定单位混用时，固定单位先分配，剩余空间再按 fr 分配。

repeat() 简化重复的轨道定义：repeat(3, 1fr) 等价于 1fr 1fr 1fr。repeat(auto-fill, minmax(200px, 1fr)) 是响应式网格的常用模式。

2.4 auto-fill vs auto-fit

两者都创建尽可能多的列轨道，区别在于空轨道的处理：auto-fill 保留空轨道（项目保持最小宽度不拉伸），auto-fit 将空轨道折叠为 0（项目拉伸填满容器）。当项目数量多到填满所有列时，两者行为完全相同。

2.5 minmax() 函数

minmax(min, max) 定义轨道大小范围，常用组合：minmax(200px, 1fr)（最小200px，弹性扩展）、minmax(0, 1fr)（允许缩小到0，防止内容溢出）。

2.6 grid-template-areas

用字符串"画"出布局结构，最直观的 Grid 布局方式：

CSS.page {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main   main"
    "footer footer footer";
  grid-template-columns: 240px 1fr 1fr;
  grid-template-rows: 64px 1fr 48px;
  gap: 16px;
}
.page-header  { grid-area: header; }
.page-sidebar { grid-area: sidebar; }
.page-main    { grid-area: main; }
.page-footer  { grid-area: footer; }

2.7 Grid vs Flexbox

维度GridFlexbox
维度二维（行+列）一维（行或列）

3. 代码示例与最佳实践

示例一：响应式页面布局

CSS.page {
  display: grid;
  grid-template-areas:
    "header  header  header"
    "sidebar content aside"
    "footer  footer  footer";
  grid-template-columns: 240px 1fr 200px;
  grid-template-rows: 64px 1fr 48px;
  gap: 16px;
  min-height: 100vh;
}
.page-header  { grid-area: header; }
.page-sidebar { grid-area: sidebar; }
.page-content { grid-area: content; }
.page-aside   { grid-area: aside; }
.page-footer  { grid-area: footer; }

@media (max-width: 1024px) {
  .page {
    grid-template-areas:
      "header  header"
      "sidebar content"
      "footer  footer";
    grid-template-columns: 200px 1fr;
  }
  .page-aside { display: none; }
}
@media (max-width: 768px) {
  .page {
    grid-template-areas: "header" "content" "footer";
    grid-template-columns: 1fr;
  }
  .page-sidebar { display: none; }
}

示例二：响应式图片网格

CSS.photo-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
.photo-grid img {
  width: 100%;
  height: 200px;
  object-fit: cover;
  border-radius: 8px;
}

/* 带特色图的画廊 */
.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 200px;
  gap: 8px;
}
.gallery .featured { grid-column: span 2; grid-row: span 2; }
.gallery .wide { grid-column: span 2; }

示例三：仪表盘布局

CSS.dashboard {
  display: grid;
  grid-template-columns: 260px 1fr;
  grid-template-rows: 56px 1fr;
  grid-template-areas: "sidebar topbar" "sidebar main";

.dashboard .sidebar { grid-area: sidebar; background: #1e293b; }
.dashboard .topbar { grid-area: topbar; display: flex; align-items: center; }
.dashboard .main { grid-area: main; padding: 24px; overflow-y: auto; }

.stats-grid {

  gap: 16px;
  margin-bottom: 24px;
}
.charts-grid {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 16px;
}

示例四：跨行跨列与重叠

CSS.layout {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: minmax(100px, auto);
  gap: 16px;
}
.item-wide { grid-column: span 2; }
.item-tall { grid-row: span 2; }
.item-featured { grid-column: span 2; grid-row: span 2; }

/* 使用 -1 引用最后一条网格线 */
.full-width { grid-column: 1 / -1; }

/* 重叠效果 */
.hero-banner { grid-column: 1 / -1; grid-row: 1 / -1; z-index: 1; }
.hero-text   { grid-column: 2 / 4; grid-row: 2; z-index: 2; align-self: center; }

示例五：Subgrid 对齐

CSS.card-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto auto 1fr auto; /* 4行：标题/元信息/内容/底部 */
  gap: 16px;
}
.card {
  display: grid;
  grid-row: span 4;
  grid-template-rows: subgrid; /* 继承父网格行定义，所有卡片行对齐 */
  gap: 8px 16px;
  background: #fff;
  border: 1px solid #e2e8f0;
  border-radius: 10px;
  padding: 16px;
}
.card .actions { margin-top: auto; }

4. 常见问题与坑点

auto-fill 和 auto-fit 有什么区别？ +

auto-fill 保留空轨道占据空间，项目保持 minmax 定义的最小宽度；auto-fit 将空轨道折叠为 0 宽度，让有项目的轨道拉伸填满。项目数量填满所有列时两者行为完全相同。选择：项目保持原始大小用 auto-fill，项目拉伸填满用 auto-fit。

为什么 grid-template-rows: 1fr 没有让行占满？ +

fr 基于剩余空间分配，需要容器有确定高度。如果容器高度由内容决定，就没有"剩余空间"，1fr 等于 auto。解决：设置 height: 100vh 或 min-height: 100vh。

fr 轨道中内容溢出怎么办？ +

1fr 的最小尺寸是 auto（由内容决定），长文本会溢出轨道。解决：使用 minmax(0, 1fr) 替代 1fr，配合项目上的 min-width: 0、overflow: hidden 和 text-overflow: ellipsis。

🚫 fr 轨道内容溢出

使用 minmax(0, 1fr) 替代 1fr，并在项目上设 min-width: 0 + overflow: hidden，防止内容撑破网格。

💡 用 -1 引用最后网格线

grid-column: 1 / -1 让项目跨越所有列。注意 -1 只在显式网格中有效。

1Grid 和 Flexbox 的区别？分别适合什么场景？
Grid 是二维布局（行+列同时控制），布局驱动；Flexbox 是一维布局，内容驱动。页面整体布局、仪表盘、跨行跨列 → Grid；导航栏、工具栏、居中 → Flexbox。最佳实践：Grid 搭骨架，Flexbox 处理组件内部。
2auto-fill 和 auto-fit 的区别？
auto-fill 保留空轨道空间，项目不拉伸；auto-fit 折叠空轨道为 0，项目拉伸填满。项目多到填满列时两者行为相同。区别仅在项目数量少于最大列数时。
3什么是 Subgrid？解决什么问题？
Subgrid 让嵌套网格继承父网格轨道定义，子网格轨道与父网格对齐。解决嵌套网格各行高度独立无法对齐的问题。典型场景：卡片列表标题/内容/底部对齐。语法：grid-template-rows: subgrid。
