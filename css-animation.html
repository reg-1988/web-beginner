CSS 动画与过渡

从 transition 到 @keyframes，掌握 CSS 动画的完整体系——让界面不只是功能性的，更是灵动和愉悦的。

1. 核心概念与定义

CSS 动画体系包含两个核心机制：过渡（Transition）和关键帧动画（Animation）。Transition 用于在两个状态之间平滑过渡，需要触发条件（如 hover、class 变化）；Animation 通过 @keyframes 定义关键帧序列，可以自动播放、循环、暂停，不需要触发条件。

Transition 是 CSS 动画的基础形式。当元素的 CSS 属性值发生变化时，Transition 让变化不是瞬间跳变而是在指定时间内平滑过渡。局限在于它只能在两个状态之间做线性插值——不知道中间过程的细节。

Animation 弥补了 Transition 的局限。通过 @keyframes 定义动画序列中的多个关键帧，浏览器在关键帧之间自动插值。Animation 还提供循环次数、方向、填充模式、播放状态等丰富控制。

动画在用户体验中扮演功能性角色：提供视觉反馈、引导注意力、表达状态变化、建立空间关系。掌握 CSS 动画不仅是技术能力，更是设计素养。

2. 关键特性与工作原理

2.1 Transition 详解

属性说明默认值
transition-property参与过渡的属性all
transition-duration过渡持续时间0s
transition-timing-function缓动函数ease
transition-delay延迟开始时间0s

简写：transition: property duration timing-function delay;。多个属性分别过渡：transition: color 0.2s, transform 0.3s ease-out;。注意：transition 应写在基础状态上，不是 hover 上。

2.2 缓动函数（Timing Function）

函数效果适用场景
linear匀速进度条、匀速旋转
ease先快后慢再慢（默认）通用过渡
ease-in慢→快元素离开画面
ease-out快→慢元素进入画面
ease-in-out慢→快→慢颜色/尺寸变化
cubic-bezier(x1,y1,x2,y2)自定义贝塞尔曲线精细控制手感
steps(n, direction)分步跳跃逐帧动画、打字机效果

常用高质量贝塞尔曲线：cubic-bezier(0.34, 1.56, 0.64, 1)（弹性回弹）、cubic-bezier(0.22, 1, 0.36, 1)（快速减速）、cubic-bezier(0.16, 1, 0.3, 1)（iOS弹性）。

2.3 Animation 详解

属性说明默认值
animation-name@keyframes 名称none
animation-duration一次动画持续时间0s
animation-timing-function缓动函数ease
animation-delay延迟开始时间0s
animation-iteration-count循环次数1
animation-direction播放方向normal
animation-fill-mode填充模式none
animation-play-state播放状态running

2.4 animation-fill-mode 详解

值动画开始前动画结束后
none原始样式回到原始样式
forwards原始样式保持最后一帧
backwards应用第一帧回到原始样式
both应用第一帧保持最后一帧
💡 实用建议

入场动画推荐 animation-fill-mode: both，确保 delay 期间应用第一帧样式（如 opacity: 0），结束后保持最终帧。

2.5 GPU 加速与性能

浏览器渲染管线：Style → Layout → Paint → Composite。仅 transform 和 opacity 只触发 Composite（高性能），避免在动画中使用 width/height/top/left（触发 Layout）和 box-shadow/color（触发 Paint）。

will-change 向浏览器提示即将变化，让浏览器提前优化。但不要滥用——仅在即将动画的元素上使用，动画结束后移除。

2.6 prefers-reduced-motion

检测用户是否开启了"减少动画"选项，是可访问性的重要考量：

CSS@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

  transform: translateY(-2px);

.btn-primary { background: #2563eb; color: white; }
.btn-primary:hover { background: #1d4ed8; }

/* 交错入场 */
.stagger-item { opacity: 0; animation: fadeInUp 0.5s ease-out both; }
.stagger-item:nth-child(1) { animation-delay: 0.05s; }
.stagger-item:nth-child(2) { animation-delay: 0.10s; }
.stagger-item:nth-child(3) { animation-delay: 0.15s; }

/* 缩放弹入 */
@keyframes scaleIn { from { opacity: 0; transform: scale(0.9); } to { opacity: 1; transform: scale(1); } }

/* 滚动触发（配合 JS IntersectionObserver） */
.animate-on-scroll {
  opacity: 0; transform: translateY(30px);
  transition: opacity 0.6s ease-out, transform 0.6s ease-out;
}
.animate-on-scroll.visible { opacity: 1; transform: translateY(0); }

示例四：面板展开/收起

CSS/* 方案一：max-height（简单但不精确） */
.accordion-content {
  max-height: 0; overflow: hidden;
  transition: max-height 0.3s ease-out;
}
.accordion-item.open .accordion-content { max-height: 500px; }

/* 方案二：grid-template-rows（推荐，精确匹配内容高度） */
.accordion-content {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.3s ease-out;
}
.accordion-item.open .accordion-content { grid-template-rows: 1fr; }
.accordion-content > .inner { overflow: hidden; }

示例五：@property 自定义属性动画

CSS/* 渐变背景动画（原本不可能） */
@property --color-start { syntax: '<color>'; inherits: false; initial-value: #2563eb; }
@property --color-end   { syntax: '<color>'; inherits: false; initial-value: #06b6d4; }
.gradient-btn {
  --color-start: #2563eb; --color-end: #06b6d4;
  background: linear-gradient(135deg, var(--color-start), var(--color-end));
  transition: --color-start 0.3s, --color-end 0.3s;
}
.gradient-btn:hover { --color-start: #7c3aed; --color-end: #ec4899; }

/* 数字滚动 */
@property --num { syntax: '<integer>'; inherits: false; initial-value: 0; }
.counter { --num: 0; counter-reset: num var(--num); transition: --num 1s ease-out; }
.counter::after { content: counter(num); }
/* JS: element.style.setProperty('--num', 100); */

4. 常见问题与坑点

为什么 transition 不生效？ +

常见原因：① 属性不可过渡（如 display）；② transition 写在 hover 上而非基础状态；③ 未设置 duration；④ auto 值无法过渡（如 height: auto）；⑤ 初始值和最终值相同。

animation-fill-mode: forwards 和 both 有什么区别？ +

forwards 只保持最后一帧，delay 期间用原始样式；both 同时具有 forwards 和 backwards 效果，delay 期间应用第一帧，结束后保持最后一帧。入场动画推荐 both。

如何实现 height: auto 的过渡？ +

四种方案：① max-height 技巧（简单不精确）；② grid-template-rows: 0fr→1fr（推荐，精确）；③ JS 计算 scrollHeight（精确但需JS）；④ @property 注册自定义属性（前沿，兼容性有限）。

🚫 性能大忌：动画中使用 width/height/top/left

这些属性触发 Layout 重排，性能开销极大。始终使用 transform: translateX/Y() 替代 top/left，transform: scale() 替代 width/height 变化。transform 和 opacity 是动画的"黄金属性"。

⚠ display: none 与动画冲突

display: none → block 不可过渡。解决方案：用 visibility + opacity 组合、@keyframes 替代 transition、或 JS 分两步操作（先 display:block，下一帧再触发过渡）。

1transition 和 animation 有什么区别？
transition 需触发条件，只在两状态间过渡，执行一次停止；animation 通过 @keyframes 定义多关键帧，可自动播放、循环、暂停。简单状态切换→transition；循环动画、多阶段动画→animation。
2如何优化 CSS 动画性能？
只用 transform 和 opacity 做动画（仅触发 Composite）；避免触发 Layout 的属性；合理使用 will-change；确保动画元素在独立合成层；尊重 prefers-reduced-motion。
3如何实现 height: auto 的过渡？
推荐 grid-template-rows: 0fr → 1fr 方案，精确匹配内容高度，纯 CSS 实现。备选：max-height 技巧（简单不精确）、JS 计算 scrollHeight、@property 方案。
