Flexbox 布局

Flexbox 是 CSS 一维布局的利器——用最少的代码实现最灵活的对齐、分配与排列，是日常开发中使用频率最高的布局方案。

1. 核心概念与定义

Flexbox（弹性盒子布局）是 CSS3 引入的一种一维布局模型，旨在提供更高效的方式来排列、对齐和分配容器内项目之间的空间，即使项目的大小未知或动态变化。与传统的 float 和 position 布局相比，Flexbox 能以极少的代码实现复杂的对齐和分配效果。

Flexbox 的核心思想是弹性：容器可以根据可用空间自动调整子项的大小和位置。开发者不需要计算具体的像素值，只需声明"我希望这些项目如何排列和分配空间"，浏览器会自动完成计算。这解决了传统布局中许多令人头疼的问题：垂直居中、等高列、剩余空间分配等。

Flexbox 是一维布局——它一次只处理一个方向（行或列）上的排列。如果你需要同时在行和列两个维度上进行控制，应该使用 Grid 布局。但在实际开发中，Flexbox 的使用频率远高于 Grid，因为大多数布局需求（导航栏、工具栏、卡片列表、表单行）本质上是一维的。

2.3 主轴与交叉轴

Flex 布局的核心概念是两条轴：主轴（main axis）是 flex-direction 定义的方向，项目沿主轴排列；交叉轴（cross axis）与主轴垂直。当 flex-direction: row 时，主轴是水平的，交叉轴是垂直的；当 flex-direction: column 时则相反。justify-content 控制主轴对齐，align-items 控制交叉轴对齐——记住这个对应关系是掌握 Flexbox 的关键。

2.4 flex-grow / shrink / basis 深入

flex-grow 定义项目在剩余空间中的放大比例。如果所有项目 flex-grow 为 1，则平分剩余空间；如果某项为 2，则它分得的空间是其他项的两倍。flex-shrink 定义空间不足时的缩小比例，默认为 1（等比缩小），设为 0 则不缩小。flex-basis 定义项目在分配多余空间之前的初始大小，auto 表示由项目自身宽高决定。

💡 flex 简写最佳实践

推荐使用 flex 简写而非单独设置三个属性。常见简写：flex: 1 等价于 flex: 1 1 0%（弹性填充）；flex: auto 等价于 flex: 1 1 auto（基于内容弹性）；flex: none 等价于 flex: 0 0 auto（固定大小不弹性）。最常用的是 flex: 1。

3. 代码示例与最佳实践

示例一：水平垂直居中

CSS/* === 最简单的居中方案 === */
.center {
  display: flex;
  justify-content: center;  /* 主轴居中 */
  align-items: center;      /* 交叉轴居中 */
  height: 100vh;
}

/* 简写版 */
.center-compact {
  display: flex;
  place-items: center;     /* align-items + justify-items */
  place-content: center;   /* align-content + justify-content */
  height: 100vh;
}

/* 行内 flex 居中 */
.inline-center {
  display: inline-flex;
  align-items: center;
  gap: 6px;
}

4. 常见问题与坑点

flex: 1 和 flex: auto 有什么区别？ +

flex: 1 等价于 flex: 1 1 0%，flex-basis 为 0%，意味着项目忽略自身内容大小，完全按 grow 比例分配空间。flex: auto 等价于 flex: 1 1 auto，flex-basis 为 auto，项目先按内容大小分配空间，剩余空间再按 grow 比例分配。结果：flex: 1 的项目等大（不管内容多少），flex: auto 的项目大小取决于内容。

为什么 flex 容器内的文本溢出不显示省略号？ +

Flex 项目的最小宽度默认由内容决定（min-width: auto），不会缩小到内容以下。文本溢出省略号需要项目宽度受限才能触发。解决方案：给 flex 项目设置 min-width: 0（允许缩小到 0）或 overflow: hidden，同时配合 text-overflow: ellipsis 和 white-space: nowrap。

flex-basis 和 width 有什么区别？ +

在 flex 容器中，flex-basis 优先于 width。如果同时设置了 flex-basis 和 width，flex-basis 生效。flex-basis: auto 时才回退到 width。关键区别：flex-basis 是"在分配剩余空间之前"的初始大小，width 是绝对大小；flex-basis 可以被 flex-grow 和 flex-shrink 影响，而 width 不参与弹性计算。

🚫 常见坑：flex 项目 min-width: auto

Flex 项目的默认 min-width 是 auto（而非 0），这意味着项目不会缩小到内容以下。当内容是长文本或宽图片时，项目会撑破容器。解决方案：在需要缩小的项目上显式设置 min-width: 0。同理，flex-direction: column 时设 min-height: 0。

💡 用 gap 替代 margin 控制间距

传统做法用 margin 来控制 flex 项目间距，但需要处理最后一个项目的 margin。gap 属性只在项目之间添加间距，首尾不留空白，更符合直觉。gap 同时适用于 flex 和 grid 容器。

1flex: 1 代表什么？flex: 0 1 auto 和 flex: 1 1 0% 有什么区别？
flex: 1 是 flex: 1 1 0% 的简写，表示项目可放大(shrink=1)、可缩小(shrink=1)、初始大小为 0%。flex: 0 1 auto 表示不放大、可缩小、初始大小由内容决定。核心区别在 flex-basis：0% 使所有项目忽略内容大小，完全按 grow 比例等分空间；auto 使项目先按内容分配，剩余空间再按比例分配。
2如何用 Flexbox 实现水平垂直居中？
父容器 display: flex + justify-content: center + align-items: center。justify-content 控制主轴对齐，align-items 控制交叉轴对齐，两者同时 center 即可。这是最简洁可靠的居中方案，替代了传统负 margin、transform 等技巧。
3Flexbox 和 Grid 布局分别适合什么场景？
Flexbox 是一维布局，适合单行或单列的项目排列（导航栏、工具栏、卡片列表、表单行、居中）。Grid 是二维布局，适合同时控制行和列的复杂布局（页面骨架、仪表盘、图库网格）。最佳实践：Grid 搭页面骨架，Flexbox 处理组件内部排列，两者配合使用。
